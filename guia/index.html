O que é

Mods: o Claude Code do jeito que você quer

Se você queria que o Claude Code fizesse algo diferente, pede para ele, e ele muda. Um mod é um pequeno módulo JavaScript, distribuído dentro de um plugin, que roda dentro do Claude Code: desenha na tela, cria comandos e pergunta com botões antes de uma ação.

🔥 Cache Keeper

Mostra se o cache do chat está quente ou frio, quanto custaria recomeçar frio, mantém chats grandes aquecidos e passa um chat longo para um novo com /handoff.

🔴 Recording Mode

/rec antes de gravar: chaves, e-mails, valores e arquivos .env somem da tela em todos os chats abertos.

📊 Goal Meter

Barra de progresso e previsão de término para o /goal, feitas a partir do plano de tarefas do próprio Claude.

🛡️ Collision Guard

Antes de editar um arquivo que outro chat mudou nos últimos 30 minutos, pergunta: seguir, mover para um worktree ou cancelar.

➡️ Next Steps

Ao fim de cada resposta, até 3 sugestões de próximo prompt como botões. Uma tecla envia; outra descarta.

🔒 Tudo local

Os dados ficam em ~/.claude/mods-data/. Nenhum mod faz chamada de rede própria. Licença MIT.

Conceitos em 2 minutos

Como um mod funciona

O mod carrega quando o chat começa e reage a eventos: um prompt enviado, uma ferramenta prestes a rodar, o fim de uma resposta. Em cada evento ele pode desenhar, perguntar ou guardar estado.

Chat começa→ Mod carrega→ Evento (prompt, ferramenta, fim da resposta)→ Desenha · pergunta · registra

Mod × hook × skill

Skill é instrução em Markdown que o Claude lê. Hook clássico é um comando de shell que bloqueia ou permite, sem interface. Mod faz o que o hook faz e ainda desenha na tela, cria comandos e lembra estado.

Contexto

Tudo o que está no chat. A cada mensagem, o modelo relê o contexto inteiro. Um chat longo passa fácil de 100k tokens.

Cache de prompt

Reler do cache custa ~10 % do preço. O cache expira com o chat parado (5 min ou 1 h). Na volta, a primeira mensagem regrava tudo a até 2× o preço: o “recomeço frio”.

/goal e worktree

/goal roda um trabalho longo até a meta ser atingida. Um git worktree é uma segunda pasta do mesmo repositório, para dois chats não pisarem nos mesmos arquivos.

Pré-requisitos

O que você precisa

Duas coisas: uma versão recente do Claude Code e os mods liberados na sua conta.

Claude Code 2.1.287+

Funciona no terminal e na aba Code do app Desktop.

claude --version
claude update   # se for mais antigo

Mods liberados

Numa pasta vazia: “no hooks module to load” = pode carregar; “served off” = ainda não liberado (instale assim mesmo).

claude plugin test
Guia de uso · passo a passo

Instalar em quatro passos

O jeito mais simples é pedir ao próprio Claude. Abaixo está o caminho manual, comando por comando.

1

Baixe o repositório

Clone e copie para a pasta onde o marketplace vai morar (ela precisa ficar fixa).

git clone https://github.com/inematds/5-mods
cp -a 5-mods ~/.claude/5-mods
2

Registre o marketplace

O repositório é um marketplace de plugins chamado 5-mods.

claude plugin marketplace add "$HOME/.claude/5-mods"
3

Instale os mods, um por vez

Não em paralelo: todos escrevem no mesmo arquivo de configuração. Instale só os que quiser.

claude plugin install cache-keeper@5-mods
claude plugin install recording-mode@5-mods
claude plugin install goal-meter@5-mods
claude plugin install collision-guard@5-mods
claude plugin install next-steps@5-mods
4

Abra um chat novo e teste

O mod carrega quando o chat começa (/clear e /reload-plugins não contam). Se /guard responder, está tudo rodando.

claude
/guard   # responde com o que o Collision Guard está vendo
★

Ou peça ao Claude

Ele confere a versão, copia, registra, instala os cinco e deixa uma nota no seu CLAUDE.md global.

Instale os cinco mods do Claude Code desta pasta: ~/5-mods.
Siga o INSTALL-FOR-CLAUDE.md que está nela.
↻

Atualizar e remover

A instalação é uma cópia: nada muda até você atualizar e abrir um chat novo.

claude plugin marketplace update 5-mods
claude plugin update next-steps@5-mods
claude plugin uninstall next-steps@5-mods
Os 5 mods em detalhe

O que cada um faz e como usar

Cada mod tem seus comandos. Todos podem ser ligados e desligados sem desinstalar.

🔥

Cache Keeper

Uma linha acima do prompt mostra o estado do cache, o tamanho do contexto, quanto custaria regravar e o gasto da sessão. Fica amarela 5 min antes de esfriar, com botão keep warm. Mostra também os limites de 5 h e semanal (amarelo em 80 %, vermelho em 95 %). Num chat acima de 150k tokens com cache frio, pergunta antes de enviar: enviar, compactar antes ou cancelar.

● cache warm 42m │ ctx 412k │ rewrite ≈ $3.30 │ session $5.12
/keepwarm 2      # mantém aquecido por 2 h (padrão 4, máx. 24)
/board           # todos os chats locais num painel
/handoff         # resume, limpa e continua num chat novo
/cache big 100k  # perguntar antes de envio frio a partir de 100k

Os valores em dólar seguem a tabela da API; na assinatura viram consumo dos limites, não cobrança.

🔴

Recording Mode

Vale para todos os chats abertos em até 3 s. Mascara chaves de API, valores de .env, e-mails, nomes, telefones, endereços, números de documento e valores em dinheiro; esconde resultados inteiros de ferramentas de e-mail, agenda, CRM e finanças; fecha arquivos sensíveis. O Claude continua recebendo os dados reais: só a tela muda.

/rec          # liga (● REC vermelho acima do prompt)
/rec strict   # mascara também todo número grande e porcentagem
/rec config   # cria ~/.claude/mods-data/recording-mode/config.json
/rec off

No Brasil: as palavras de negócio estão em inglês. R$, CPF/CNPJ e “faturamento” podem passar: use /rec strict, preencha names e privatePaths no config e revise o vídeo antes de publicar.

📊

Goal Meter

Com /goal, o Claude escreve o plano (tarefas P, M ou G, valendo 1, 2 e 3) e marca cada uma. A previsão usa o ritmo do próprio goal e aparece depois de 2 tarefas. Se surgir trabalho novo, o plano cresce e a barra pode recuar. Não faz chamadas extras ao modelo.

/goal migrar os testes para Vitest e deixar todos passando
5 of 8 tasks · 69%  ████████░░░  38m elapsed · about 17m left
/goals             # lista deste chat + metas dos outros chats (12 h)
/goals strict on   # sem editar arquivo antes de o plano existir
🛡️

Collision Guard

Antes de Edit, Write ou NotebookEdit, confere se outro chat aberto mudou aquele arquivo na janela de tempo. Se sim: Proceed (edita), Move to a worktree (quando o arquivo está no git) ou Cancel. Nada é acrescentado ao prompt.

/guard             # o que ele está vendo
/guard window 60   # janela de 60 min em vez de 30
/guard off
➡️

Next Steps

Quando a resposta termina, o mod pergunta ao modelo, reaproveitando o histórico do chat que já está em cache, quais são os próximos passos mais úteis. As sugestões saem no idioma em que você escreve. Fica em silêncio enquanto o Recording Mode está ligado. Custa uma consulta pequena por resposta, quase toda leitura de cache.

→ next steps
  [j] Rode os testes do módulo de login
  [k] Faça o commit das mudanças
  [l] Atualize o README com o novo comando
  [d] dismiss
/next off   # desliga (vale para os chats seguintes)

Crie o seu

Seu próprio mod, em português

Não precisa saber JavaScript: descreva o que quer ver e quando. Os cinco mods deste repositório são bons modelos; o next-steps é o menor (~180 linhas).

Quero um mod que, quando eu digitar /pomodoro, mostre acima do prompt
um contador de 25 minutos e me avise com um toast quando acabar.

# estrutura de um mod
meu-mod/.claude-plugin/plugin.json   # nome, versão, descrição
meu-mod/hooks/hooks.json             # { "modules": ["./register.mjs"] }
meu-mod/hooks/register.mjs           # export const register = (on) => { ... }

claude plugin validate --strict ./meu-mod
claude plugin test ./meu-mod

Para mudar um mod existente, peça: “o collision guard deve olhar 60 minutos para trás”, “nunca esconda o nome da minha empresa no modo gravação”. O Claude segue o CUSTOMIZE.md: primeiro um comando, depois o arquivo de configuração, por último o código.

Dúvidas

Perguntas frequentes

Instalei e nada aparece

Mods carregam quando o chat começa. Saia e rode claude de novo, depois digite /guard.

“served off”

Sua conta ainda não recebeu os mods. A instalação fica pronta e passa a funcionar quando a liberação chegar.

Um comando não existe

Outro plugin já usava o nome. Use o alternativo: /next-steps, /ck-cache, /ck-handoff, /recording, /goal-meter, /collision-guard.

Os valores em dólar são cobrados?

Não na assinatura: viram consumo dos limites de 5 h e semanal. São estimativas pelo preço da API.

Funciona no app Desktop?

Sim, na aba Code. A linha com botões acima do prompt é do terminal; no Desktop aparecem os rótulos do rodapé e os comandos.

Mudei o código e nada mudou

O Claude Code roda uma cópia. Suba a versão no plugin.json, atualize o marketplace e o mod, e abra um chat novo.
