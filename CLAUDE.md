# Claude Code mods (5-mods)

This folder is a plugin marketplace, `5-mods`, holding five Claude Code mods: Cache Keeper, Recording Mode, Goal Meter, Collision Guard, and Next Steps.

- To install them, follow `INSTALL-FOR-CLAUDE.md`.
- To change how one works, follow `CUSTOMIZE.md`. Editing a file here changes nothing until the mod's version is bumped and it's reinstalled.
- Log every change to a mod in `CHANGES.md`.
