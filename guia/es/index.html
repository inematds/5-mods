Qué son

Mods: Claude Code a tu manera

Si querías que Claude Code hiciera algo distinto, se lo pides y cambia. Un mod es un pequeño módulo de JavaScript, distribuido dentro de un plugin, que corre dentro de Claude Code: dibuja en pantalla, crea comandos y pregunta con botones antes de una acción.

🔥 Cache Keeper

Muestra si el caché del chat está caliente o frío, cuánto costaría empezar de nuevo en frío, mantiene calientes los chats grandes y pasa un chat largo a uno nuevo con /handoff.

🔴 Recording Mode

/rec antes de grabar: claves, correos, montos y archivos .env desaparecen de la pantalla en todos los chats abiertos.

📊 Goal Meter

Barra de progreso y pronóstico de término para /goal, a partir del plan de tareas del propio Claude.

🛡️ Collision Guard

Antes de editar un archivo que otro chat cambió en los últimos 30 minutos, pregunta: seguir, mover a un worktree o cancelar.

➡️ Next Steps

Al final de cada respuesta, hasta 3 sugerencias de próximo prompt como botones. Una tecla lo envía; otra lo descarta.

🔒 Todo local

Los datos quedan en ~/.claude/mods-data/. Ningún mod hace llamadas de red propias. Licencia MIT.

Conceptos en 2 minutos

Cómo funciona un mod

El mod se carga cuando empieza el chat y reacciona a eventos: un prompt enviado, una herramienta a punto de ejecutarse, el fin de una respuesta. En cada evento puede dibujar, preguntar o guardar estado.

Empieza el chat→ El mod se carga→ Evento (prompt, herramienta, fin de la respuesta)→ Dibuja · pregunta · registra

Mod × hook × skill

Skill es una instrucción en Markdown que Claude lee. Hook clásico es un comando de shell que bloquea o permite, sin interfaz. Mod hace lo que hace el hook y además dibuja en pantalla, crea comandos y recuerda estado.

Contexto

Todo lo que está en el chat. Con cada mensaje, el modelo relee el contexto completo. Un chat largo supera fácilmente los 100k tokens.

Caché de prompt

Releer desde el caché cuesta ~10 % del precio. El caché expira con el chat detenido (5 min o 1 h). Al volver, el primer mensaje lo regraba todo hasta a 2× el precio: el “reinicio en frío”.

/goal y worktree

/goal ejecuta un trabajo largo hasta alcanzar la meta. Un git worktree es una segunda carpeta del mismo repositorio, para que dos chats no se pisen los mismos archivos.

Requisitos previos

Lo que necesitas

Dos cosas: una versión reciente de Claude Code y los mods habilitados en tu cuenta.

Claude Code 2.1.287+

Funciona en la terminal y en la pestaña Code de la app Desktop.

claude --version
claude update   # si es más antigua

Mods habilitados

En una carpeta vacía: “no hooks module to load” = puede cargar; “served off” = aún no está habilitado (instala igual).

claude plugin test
Guía de uso · paso a paso

Instalar en cuatro pasos

Lo más simple es pedírselo al propio Claude. Abajo está el camino manual, comando por comando.

1

Descarga el repositorio

Clona y copia a la carpeta donde vivirá el marketplace (debe quedar fija).

git clone https://github.com/inematds/5-mods
cp -a 5-mods ~/.claude/5-mods
2

Registra el marketplace

El repositorio es un marketplace de plugins llamado 5-mods.

claude plugin marketplace add "$HOME/.claude/5-mods"
3

Instala los mods, uno a la vez

No en paralelo: todos escriben en el mismo archivo de configuración. Instala solo los que quieras.

claude plugin install cache-keeper@5-mods
claude plugin install recording-mode@5-mods
claude plugin install goal-meter@5-mods
claude plugin install collision-guard@5-mods
claude plugin install next-steps@5-mods
4

Abre un chat nuevo y prueba

El mod se carga cuando empieza el chat (/clear y /reload-plugins no cuentan). Si /guard responde, todo está funcionando.

claude
/guard   # responde con lo que Collision Guard está viendo
★

O pídeselo a Claude

Él revisa la versión, copia, registra, instala los cinco y deja una nota en tu CLAUDE.md global.

Instala los cinco mods de Claude Code de esta carpeta: ~/5-mods.
Sigue el INSTALL-FOR-CLAUDE.md que está en ella.
↻

Actualizar y quitar

La instalación es una copia: nada cambia hasta que actualices y abras un chat nuevo.

claude plugin marketplace update 5-mods
claude plugin update next-steps@5-mods
claude plugin uninstall next-steps@5-mods
Los 5 mods en detalle

Qué hace cada uno y cómo usarlo

Cada mod tiene sus comandos. Todos se pueden activar y desactivar sin desinstalar.

🔥

Cache Keeper

Una línea sobre el prompt muestra el estado del caché, el tamaño del contexto, cuánto costaría regrabar y el gasto de la sesión. Se pone amarilla 5 min antes de enfriarse, con el botón keep warm. Muestra también los límites de 5 h y semanal (amarillo al 80 %, rojo al 95 %). En un chat de más de 150k tokens con caché frío, pregunta antes de enviar: enviar, compactar antes o cancelar.

● cache warm 42m │ ctx 412k │ rewrite ≈ $3.30 │ session $5.12
/keepwarm 2      # lo mantiene caliente por 2 h (por defecto 4, máx. 24)
/board           # todos los chats locales en un panel
/handoff         # resume, limpia y continúa en un chat nuevo
/cache big 100k  # preguntar antes de un envío en frío desde 100k

Los valores en dólares siguen la tabla de la API; en la suscripción se vuelven consumo de los límites, no cobro.

🔴

Recording Mode

Vale para todos los chats abiertos en hasta 3 s. Enmascara claves de API, valores de .env, correos, nombres, teléfonos, direcciones, números de documento y montos de dinero; oculta resultados completos de herramientas de correo, agenda, CRM y finanzas; cierra archivos sensibles. Claude sigue recibiendo los datos reales: solo cambia la pantalla.

/rec          # lo activa (● REC rojo sobre el prompt)
/rec strict   # enmascara también todo número grande y porcentaje
/rec config   # crea ~/.claude/mods-data/recording-mode/config.json
/rec off

En Latinoamérica: las palabras de negocio y los patrones de enmascaramiento están pensados en inglés. Los símbolos de moneda local, los números de identificación nacional (RFC, CUIT, RUT…) y términos de negocio en español como “facturación” pueden pasar: usa /rec strict, completa names y privatePaths en el config y revisa el video antes de publicar.

📊

Goal Meter

Con /goal, Claude escribe el plan (tareas P, M o G, que valen 1, 2 y 3) y marca cada una. El pronóstico usa el ritmo del propio goal y aparece tras 2 tareas. Si surge trabajo nuevo, el plan crece y la barra puede retroceder. No hace llamadas extra al modelo.

/goal migrar las pruebas a Vitest y dejar todas pasando
5 of 8 tasks · 69%  ████████░░░  38m elapsed · about 17m left
/goals             # lista de este chat + metas de los otros chats (12 h)
/goals strict on   # sin editar archivos antes de que exista el plan
🛡️

Collision Guard

Antes de Edit, Write o NotebookEdit, revisa si otro chat abierto cambió ese archivo dentro de la ventana de tiempo. Si es así: Proceed (edita), Move to a worktree (cuando el archivo está en git) o Cancel. No se agrega nada al prompt.

/guard             # lo que está viendo
/guard window 60   # ventana de 60 min en vez de 30
/guard off
➡️

Next Steps

Cuando termina la respuesta, el mod le pregunta al modelo, reutilizando el historial del chat que ya está en caché, cuáles son los próximos pasos más útiles. Las sugerencias salen en el idioma en que escribes. Se queda en silencio mientras Recording Mode está activo. Cuesta una consulta pequeña por respuesta, casi toda lectura de caché.

→ next steps
  [j] Ejecuta las pruebas del módulo de login
  [k] Haz el commit de los cambios
  [l] Actualiza el README con el nuevo comando
  [d] dismiss
/next off   # lo desactiva (vale para los chats siguientes)

Crea el tuyo

Tu propio mod, en español

No necesitas saber JavaScript: describe lo que quieres ver y cuándo. Los cinco mods de este repositorio son buenos modelos; next-steps es el más pequeño (~180 líneas).

Quiero un mod que, cuando escriba /pomodoro, muestre sobre el prompt
un contador de 25 minutos y me avise con un toast cuando termine.

# estructura de un mod
mi-mod/.claude-plugin/plugin.json   # nombre, versión, descripción
mi-mod/hooks/hooks.json             # { "modules": ["./register.mjs"] }
mi-mod/hooks/register.mjs           # export const register = (on) => { ... }

claude plugin validate --strict ./mi-mod
claude plugin test ./mi-mod

Para cambiar un mod existente, pídelo: “collision guard debe mirar 60 minutos hacia atrás”, “nunca ocultes el nombre de mi empresa en el modo grabación”. Claude sigue el CUSTOMIZE.md: primero un comando, después el archivo de configuración, por último el código.

Dudas

Preguntas frecuentes

Instalé y no aparece nada

Los mods se cargan cuando empieza el chat. Sal y ejecuta claude de nuevo, luego escribe /guard.

“served off”

Tu cuenta aún no recibió los mods. La instalación queda lista y empieza a funcionar cuando llegue la habilitación.

Un comando no existe

Otro plugin ya usaba el nombre. Usa el alternativo: /next-steps, /ck-cache, /ck-handoff, /recording, /goal-meter, /collision-guard.

¿Se cobran los valores en dólares?

No en la suscripción: se vuelven consumo de los límites de 5 h y semanal. Son estimaciones según el precio de la API.

¿Funciona en la app Desktop?

Sí, en la pestaña Code. La línea con botones sobre el prompt es de la terminal; en Desktop aparecen las etiquetas del pie y los comandos.

Cambié el código y nada cambió

Claude Code ejecuta una copia. Sube la versión en plugin.json, actualiza el marketplace y el mod, y abre un chat nuevo.
